# Frontend

Main Orbito Next.js app.

## Important folders

- `app/`: App Router pages, route groups, and page-level UI.
- `components/`: shared React components.
- `lib/`: browser helpers and shared client-side utilities.
- `public/`: static assets.
- `proxy.ts`: host normalization, auth redirects, and security headers.
- `next.config.ts`: frontend rewrites and build config.

## Good entry points

- Marketing pages: `app/(marketing)/`
- App product pages: `app/app/`
- Navbar/shared chrome: `components/`
